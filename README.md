# cj-components

[![npm version](https://img.shields.io/npm/v/@customerjourney/cj-components.svg)](https://www.npmjs.com/package/@customerjourney/cj-components)
[![license](https://img.shields.io/npm/l/@customerjourney/cj-components.svg)](./LICENSE)

Basic components to generate sales funnels and touchpoints for the CustomerJourney.js project, in JavaScript with a delicious vanilla flavor.

> Part of **[CustomerJourney.js](https://antoniofregoso.github.io/customerjourney/)** — vanilla JavaScript libraries optimized for creating sales funnels with hyper-personalized customer experience powered by artificial intelligence.

## Installation

```bash
npm install @customerjourney/cj-components
```

`@customerjourney/cj-core` is a peer dependency.
